# PvZ Fusion 4.1 English QOL

A compatibility port of **Blooms QOL** for **PvZ Fusion 4.1 English**, using Tproplay's English translation.

This patch brings the original Blooms QOL features to PvZ Fusion 4.1, including forced Pumpkin and Flower Pot fusions and the ability to hide metal objects.

**This download contains only the QOL patch, not the full game.**

## Downloads

- **Base Game:** [PvZ Fusion 4.1 English PC — Tproplay](https://github.com/Tproplay/Pvz-Fusion-Translation-Lite/releases/tag/v4.1)
- **QOL Patch:** [Download from Google Drive](https://drive.google.com/drive/folders/1ZKxkmejhJJa6j4xQley2iYD0T7WelMEK)

## Installation

1. Download [Tproplay's PvZ Fusion 4.1 English Translation](https://github.com/Tproplay/Pvz-Fusion-Translation-Lite/releases/tag/v4.1).
2. Download the [PvZ Fusion 4.1 QOL Patch](https://drive.google.com/drive/folders/1ZKxkmejhJJa6j4xQley2iYD0T7WelMEK).
3. Create a brand-new folder anywhere on your computer.
4. Extract the contents of **both ZIP files** into the new folder. Make sure the files are extracted directly into the same folder, without extra nested folders.
5. Launch `PlantsVsZombiesRH.exe`.

**Note:** The first launch may take longer than usual while MelonLoader initializes and generates the necessary files.

## Features

| Key | Function |
|---|---|
| **Left Shift** | Force Pumpkin fusions |
| **Left Alt** | Force Flower Pot fusions |
| **F10** | Toggle metal object visibility |

Normal plant fusion functionality is preserved.

## Compatibility

- **Game Version:** PvZ Fusion 4.1
- **Translation:** Tproplay's English PC version
- **Platform:** Windows PC
- **Mod Loader:** MelonLoader (included)

This patch was developed for PvZ Fusion 4.1 English. Compatibility with other versions is not guaranteed.

## Troubleshooting

If the game launches but the QOL features aren't working:

1. Make sure you're using Tproplay's PvZ Fusion 4.1 English PC version.
2. Verify that both ZIP files were extracted into the same folder.
3. Confirm that `Blooms_QOL.dll` is inside the `Mods` folder.
4. Confirm that `version.dll` is alongside `PlantsVsZombiesRH.exe`.
5. Restart the game.

If problems persist, check `MelonLoader/Latest.log` for errors.

**Note:** MelonLoader automatically generates its own log files. Existing logs are not included in the patch download.
